# ADR 0004: Технологический стек MVP

## Статус

Accepted (рекомендация; выравнивать с платформой команды)

## Контекст

Нужен стек для внутренней админки с транзакционным аудитом и SSO. Команда кредитования, как правило, уже имеет стандарт backend.

## Решение

Рекомендуемый default:

- **API:** Kotlin/Java 21 + Spring Boot 3
- **UI:** TypeScript + React (Vite) + корпоративная DS / Ant Design
- **DB:** PostgreSQL 15+
- **Auth:** OIDC (корпоративный IdP)
- **Migrations:** Flyway/Liquibase
- **Obs:** OpenTelemetry + Micrometer

Если платформа кредитования уже на другом стеке (.NET/Go/Node) — сохраняем **архитектурные инварианты** (транзакционный audit, actor_id, action_id, version), а не навязываем Java.

## Последствия

(+) Быстрый путь к production-практикам банка.  
(+) Легко найти инженеров и обвязки security.  
(−) Финальный выбор языка = решение техлида направления по факту текущего ландшафта.
